# Tink frontend design contract

Updated 2026-10-24. The latest request authorizes a React frontend foundation. Tink uses forest green, cream, and muted gold. It serves people with speaking and communication difficulties. Peter Pan is a subtle story cue; the supplied images remain inspiration.

## Primary job and screens
- **Home:** A Gilded Herbarium landing page introduces Tink and routes to the working communication tools. It is the destination for the proposed cinematic intro.
- **Communicate:** Compose a message, read it aloud, adjust speed, and use editable quick phrases.
- **Listen:** Start/stop browser speech recognition, edit live text, copy it, or save it explicitly. Explain unsupported browsers.
- **Camera:** Grant permission on start, view a live preview, stop it, and see the honest backend result placeholder.
- **Conversation:** Read a clearly labeled sample or locally saved transcript and request fixed mock clarification/response suggestions.
- **Settings:** Change system/light/dark appearance, contrast, text size, and motion independently.

The Communicate workspace leads with typed speech and quick phrases. Other tasks stay one navigation action away.

The home page uses the reference prototype's short headline, explanation, two actions, one botanical illustration, and Listen / Consider / Connect sequence. Its primary action enters Communicate. The functional app retains the same five task screens and settings.

## Visual direction
A warm cream reading plane with forest green typography and controls. Muted gold accents one small star-thread motif. The interface favors spacious type, flat tonal surfaces, and clear labels. This is a restrained Peter Pan cue without a fantasy scene.

Taste Skill direction: **Editorial greeting**, seed 1462396506. Use its centered column and tonal panels. The dealt count tiles are omitted because there are no meaningful counts; the message composer and quick phrases occupy the home. A labeled sidebar becomes visible horizontal navigation on mobile. This is a foundation the user can revise.

The home intro is a short procedural wordmark scene on cream. The user-supplied 5×2 fairy silhouette sheet replaces the earlier SVG fairy completely: ten transparent frames are tinted forest green without changing their shapes. A standing silhouette initially occupies the I position between T and N, while the actual i strokes stay hidden. After a pause, standing frames flutter and turn with a full-body perspective flip; flight frames then follow the existing authored cubic Bézier path with tangent-based banking and restrained gold dust. The i strokes draw in after she leaves, before the homepage reveal. Skip and Replay remain available; reduced motion shows the standing fairy as I without travel. The T/n/k lettering, landing page, and product screens stay as they were. The earlier referenced sketch was not present in its pasted attachment, so the current lettering remains open to refinement against it.

## States and honesty
Camera frames are neither stored nor sent. Browser speech starts after a user action. Text to speech uses the device's voice service. Saved transcripts and phrases live in this browser's local storage. Conversation suggestions are fixed mock examples and explicitly labeled. No interface claims live CV or AI analysis.

## Accessibility target and verification
Aim for WCAG 2.2 AA. Keep controls labeled, focus visible, touch targets large, status messages readable, and every task available by keyboard. Appearance, high contrast, reduced motion, and text scaling compose independently. Verify actual browser behavior and representative phone, tablet, and desktop layouts before claiming any check passed.
